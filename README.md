# Draggable Lists Reforged
Just a port of "[Draggable Lists](https://modrinth.com/mod/draggable-lists)" to newer versions.

**Thanks to the original author, [mrmelon54](https://github.com/MrMelon54)!**

## Info

- This mod makes it so resource packs and servers are draggable because who loves pressing buttons repeatedly just to move an item in a UI.
- Original mod: [Draggable Lists](https://modrinth.com/mod/draggable-lists)
- [Modrinth](https://modrinth.com/mod/draggable-lists-r)
